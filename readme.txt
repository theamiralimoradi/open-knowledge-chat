A generic Persian-first, configurable WordPress AI assistant.

== Description ==
- Provider-neutral OpenAI-compatible chat completions API.
- No API keys or service URLs distributed with plugin.
- Floating and shortcode-based chat, lead capture, human review, knowledge bank and article ideas.
- Displays source links as buttons and suggests related questions.

== Installation ==
1. Upload the plugin ZIP and activate it on a staging site.
2. Configure API Key, HTTPS Base URL, Model ID and consultation URL in WordPress admin.
3. Test connectivity, then publish the draft landing page /ai-chat/ if desired.
4. Review privacy and abuse-prevention settings before enabling public chat.

== Notes ==
Format-only phone check, no phone verification. Retrieval is keyword-based rather than vector embeddings. API and privacy policies remain the site operator's responsibility.
